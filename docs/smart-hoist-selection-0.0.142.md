# Module Unit Studio 0.0.142 — 권상점 선택·완화 추천

## 사용자 확인 목록

- 모델 전체 질량 가중 위치는 `모델 무게중심(CoG)`으로 표시한다.
- G1~G4의 선택 Node 비가중 평균은 `G# 권상점 중심`으로 표시한다.
- 첫 권상점을 찍으면 같은 Z만이 아니라 CoG 대칭성, 수평 스팬, 현재 형상 확장성, 부재 연결을 반영한 다음 후보를 표시한다.
- 민트는 권장 후보, 노랑은 Z 단차 확인 후보, 주황은 Strict OFF 완화 후보이다.
- Strict ON에서는 엔진 Z 한계(500 mm)를 넘는 후보를 자동 하이라이트하지 않는다.
- 수동 후보 표시 Tolerance는 구역 기반 자동 추천의 Z 탐색폭에 영향을 주지 않는다.
- Strict OFF 자동 추천의 마지막 라운드는 전 단면 Node와 추천 품질 완화 조합까지 탐색한다.
- 완화 라운드에서 찾은 후보는 PASS로 승격하지 않고 WARN으로 표시한다.
- 장비별 허용 권상점 수, 유효 Node, 양의 와이어 길이, Stage 6 전도 판정은 완화하지 않는다.
