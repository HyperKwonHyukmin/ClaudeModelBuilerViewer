# Module Unit Studio 0.0.143 — 최소 권상 면적·화면 대응

## 사용자 확인 목록

- 구역 기반 자동 추천의 3·4점 그룹은 해당 구역 선택 가능 Node의 XY 볼록 포락 면적 대비 10% 이상이어야 한다.
- 10% 미만인 좁은 3·4점 조합은 Strict ON/OFF와 관계없이 추천 목록에서 제외한다.
- 2점 권상은 면적이 정의되지 않으므로 기존 구역 대비 최대 거리 35% 기준을 유지한다.
- 1024px 이하 화면에서는 좌측 작업 패널과 상단 탭 간격이 자동으로 줄어든다.
- 820px 이하 화면에서는 상단 탭이 아이콘 모드로 전환되어 3D 뷰 폭을 보존한다.
- 680px 이하 높이에서는 상단 리본 높이를 줄이고 좌측 작업 패널은 내부 스크롤을 유지한다.
- 3D 렌더 픽셀 비율은 최대 2배로 제한하고, 일시적인 0×0 리사이즈는 카메라에 적용하지 않는다.
