# Module Unit Studio 0.0.132 — 뷰어 사용성 개선

2026-09-08

## 변경 사항

- 노드 선택 반경을 화면 기준 10px로 통일. 확대 배율과 모델 크기에 좌우되지 않으며 겹친 노드는 화면 거리와 깊이로 판별한다.
- 실제 교차점이 없는 가는 부재도 중심선 주변 6px에서 선택한다. RBE 선택 범위 역시 직교 투영 배율로 계산한다.
- 클릭·호버·더블클릭이 같은 판정 경로를 사용한다. 숨겨진 레이어, 삭제·필터로 축소된 인스턴스는 제외한다.
- 노드와 선택 마커를 화면 크기로 표시한다. 확대해도 구체가 연결 부재를 가리지 않는다. 노드 크기는 작게/표준/크게로 변경한다.
- 마우스를 올린 노드·요소를 흰색으로 미리 표시한다. 권상/가서포트/Rigid의 Shift 선택 중에도 같은 노드를 미리 확인할 수 있다.
- 선택/회전/이동 버튼으로 왼쪽 드래그 동작을 명시한다. 선택 모드는 회전을 차단하며 오른쪽 드래그 이동과 휠 확대는 유지한다.
- 선택 확대(Z)는 선택한 노드·요소·RBE를 중심으로 확대한다. 전체(Home), 등각(F), 표준 뷰는 전체 모델의 무게중심으로 복귀한다.
- 회전 관성을 제거해 드래그를 멈추면 카메라도 멈춘다. Trackball A/S/D 키와 표준 뷰 단축키 충돌을 제거한다.
- 뷰어 도구 모음에서 선택 대상과 음영/반투명/와이어프레임/노드만 표시를 조절한다.
- 툴팁을 창 안에 배치하고 카메라 이동 시 이전 툴팁을 지운다.

선택 전 강조와 엔티티별 선택 필터는 [Altair HyperMesh Graphical Selection](https://help.altair.com/2022/hwdesktop/hwx/topics/user_interface/selection_c.htm)의 작업 방식을 참고했다.

## 검증

- Vitest: 37개 파일, 661개 테스트 통과. 픽셀 선택 반경, 확대 배율, 겹친 노드, 가림, 숨김/삭제, 가는 부재 선택 회귀 테스트 포함.
